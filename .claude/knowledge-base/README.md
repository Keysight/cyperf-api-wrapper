# Knowledge Base: cyperf-api-wrapper
Generated: 2026-07-09 | Plugin: knowledge-base v3.5.0 | Last incremental refresh: 2026-07-31 (git-history patch covering commits through `835526c`, no re-discovery/IQ/EQ)

## Product Profile
- **Purpose**: Python client SDK for the Keysight CyPerf network/security performance-test controller — a mostly OpenAPI-generated REST client (`pip install cyperf`) topped with a hand-written `TestRunner`/CLI helper layer and a HATEOAS "dynamic model" layer for writing test-automation scripts.
- **Stack**: Python 3.8–3.12, pydantic ≥2, urllib3 ≥2.2, python-dateutil, typing-extensions; generated by [OpenAPI Generator](https://openapi-generator.tech) (Python/pydantic template). No web framework — this is an SDK/library, not a service.
- **Scale**: 488 Python files / ~145k LOC total (as of the Jul-10/14 2026 regen + sample-script commits), but the overwhelming majority is generator output: 454 model files (`cyperf/models/`), 16 API classes / ~322 operations (`cyperf/api/`; grew from 312 when `AgentsApi` gained ~10 new compute-resource/front-panel-port ownership operations), 469 generated doc pages (`docs/`). Hand-written surface is small and concentrated: `cyperf/utils.py` (636 lines), `cyperf/dynamic_model_meta.py` (584 lines), plus targeted edits inside `api_client.py` / `configuration.py`, and 7 sample scripts (~60k combined incl. one config zip and one pcap fixture).
- **Architecture**: Generated OpenAPI SDK, layered: `Configuration`/`ApiClient`/`RESTClientObject` (HTTP+OAuth2) → 16 generated `*Api` classes (~322 operations) → 454 generated pydantic models → a hand-written `DynamicModel` metaclass that wraps every model with lazy HATEOAS link-following, `.update()`/`.delete()`/`.refresh()`, and async-operation polling → `utils.TestRunner` + CLI helpers for scripting on top. Distributed as a PyPI package (internal Keysight/Bitbucket, `bitbucket.it.keysight.com/scm/isgappsec/cyperf-api-wrapper`), consumed by internal regression suites (e.g. the "appsec-automation" repo, per commit history).
